# 使用手册

按下面的任务查找说明。页面、账号和文件属于日常操作；权限和界面设置放在管理文档中。

| 操作 | 文档 |
| --- | --- |
| 创建、编辑、移动页面，查看旧版本 | [页面与修订](/docs/guides/pages) |
| 编写链接、模板、分类和重定向 | [Wikitext](/docs/guides/wikitext) |
| 注册、重置密码、设置语言和时区 | [账号与个人设置](/docs/guides/accounts) |
| 上传文件、在正文插入图片 | [文件与媒体](/docs/guides/files) |

| 修改侧边栏、公告或页面样式 | [界面与系统页面](/docs/administration/interface) |

## 插件功能

评论、用户资料、私信、审核和通知需要对应插件。站点未安装或未启用插件时，相关入口可能不会显示。

- [评论](/docs/plugins/comments)与[用户资料、好友和私信](/docs/plugins/social-profile)
- [编辑审核](/docs/plugins/moderation)与[滥用过滤器](/docs/plugins/abuse-filter)
- [注册问答](/docs/plugins/registration-quiz)与[编辑验证码](/docs/plugins/confirm-edit)
- [通知](/docs/plugins/echo)与[AI 编辑提案](/docs/plugins/ai-agent)

需要查找特殊页面时，打开站点的“特殊:特殊页面”。可用页面会随已安装插件变化。
